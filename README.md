# 🤖 Chintu AI: Your Rude DSA Mentor
---
Chintu AI is a specialized AI-powered instructor designed exclusively for Data Structures and Algorithms (DSA).Chintu is a world-class expert who only cares about Big O notation, sorting algorithms, and efficient data structures.
If you ask him about your personal life, he’ll roast you. If you ask him about a Binary Search Tree, he’ll give you the most optimized implementation you've ever seen.

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env](.env) to your Gemini API key
3. Run the app:
   `npm run dev`
